# Deliverable 1 – AI Note

## Project

**TeamPTea POS**

---

# AI Prompt

**Prompt Used:**

> We are a team of five BSIT students developing a **TeamPTea POS (Point of Sale System)** for a small local milk tea business. The project must be completed within 10 weeks and should focus on CRUD functionality. Review our project scope and identify:
>
> 1. Any missing CRUD operations.
> 2. Any missing application screens or UI states (empty state, error state, delete confirmation, etc.).
> 3. Features that are too advanced for a 10-week student project and should be removed.
> 4. Suggestions to improve the project while keeping the scope realistic.

---

# AI Response Summary

The AI reviewed the proposed TeamPTea POS project and concluded that the core CRUD functionality is appropriate for a 10-week software development project. It confirmed that the system should include Create, Read, Update, and Delete operations for the main record types such as Products, Customers, Orders, and Sales Records.

The AI also recommended adding important user interface states that are commonly overlooked, including:

* Empty state when no records exist.
* Error state when an operation fails.
* Delete confirmation dialog before removing a record.
* Success messages after saving or updating data.
* Input validation for required fields and invalid values.

Additionally, the AI suggested avoiding advanced features that could increase development time, such as:

* Online ordering and delivery integration.
* Customer loyalty and reward systems.
* Mobile application support.
* Online payment gateway integration.
* Inventory forecasting and business analytics dashboards.

---

# Final Team Decision

After reviewing the AI recommendations, the team agreed to keep the project focused on the essential Point of Sale functions required by a small milk tea business.

The final project scope includes:

* Product Management
* Customer Management
* Order Management
* Sales Record Management
* Basic Inventory Tracking
* Receipt Printing
* Sales Reports

The team decided **not** to include online ordering, delivery services, customer rewards, mobile applications, or advanced analytics because these features are beyond the project's intended scope and timeline.

The AI recommendations helped verify that the project remains realistic, manageable, and achievable within the 10-week development period while satisfying the required CRUD functionality.
